# MLOps Orlova

Домашние работы по дисциплине **MLOps Basic**. Все четыре работы подготовлены **отдельно**, каждая запускается из своей папки.

| Работа | Тема | Содержание |
|---|---|---|
| [HW1](HW1/) | `uv` · Ruff · ty | Минимальный типизированный Python-проект, настройки инструментов и тесты |
| [HW2](HW2/) | Git · GitFlow | Коммиты, ветвление, merge, выпуск, резервная история `history.bundle` |
| [HW3](HW3/) | DVC | Синтетические данные, remote, `dvc.yaml`, `dvc.lock`, три стадии ML-пайплайна |
| [HW4](HW4/) | Testing | Unit, integration и E2E тесты загрузки данных, модели и обучения |

## Запуск

Откройте нужную папку `HW1`–`HW4` и следуйте её `README.md`. Для HW1, HW3 и HW4 используется [uv](https://docs.astral.sh/uv/); для HW2 достаточно Python и Git. Общий запуск тестов Python без дополнительных зависимостей из каждой папки: `python -m pytest -q` (при установленном pytest), для HW2 — `python -m unittest discover -s tests -v`.

Данные, модели, lockfile и кеши, автоматически создаваемые инструментами, не выдаются за результаты проверок, которые не выполнялись. На этапе подготовки локальные Python-тесты дали результаты: HW1 — 5, HW2 — 6, HW3 — 15 (один DVC CLI тест пропущен), HW4 — 21. Запуск Ruff, ty, DVC CLI и GitHub Actions должен дополнительно подтвердиться в рабочем окружении.

### Особенности

- **HW2:** изолированную историю Git с ветками нельзя физически вложить в другую историю Git; для изучения приложен файл `HW2/history.bundle` (команда `git clone history.bundle hw2-history`).
- **HW3:** небольшой архив `HW3/remote_seed.zip` нужен только для демонстрационного восстановления локального DVC remote. Выполните `python scripts/bootstrap_remote.py` из HW3, затем `uv run dvc pull` и `uv run dvc repro`. Настоящее хранилище создаётся **за пределами** Git-репозитория.
- **CI:** настоящие GitHub Actions скрипты находятся в корневой `.github/workflows/`; все работы остаются изолированными по директориям.
